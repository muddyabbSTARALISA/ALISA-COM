# Alisa Companion — Minecraft Forge 1.20.1

Мод-компаньон с персонажем Алей, основанным на предоставленном пользователем референсе.

## Требования
- Minecraft Java Edition 1.20.1
- Minecraft Forge 47.x (проект настроен на Forge 47.4.28)
- Java 17

## Возможности версии 0.6.0
- Сущность-компаньон Аля и яйцо призыва.
- Приручение печеньем или сладкими ягодами.
- Следование за владельцем и переключение «сидеть / следовать» по ПКМ.
- Модель, текстура и базовые анимации из предыдущей версии.
- Сохранение отношений от 0 до 99 с шагом 0,5 и статусами.
- Подарки: шоколад и газировка (+1 очко), печенье и сладкие ягоды (+0,5 очка); действует КД подарков.
- Крафт шоколада и газировки.
- Три вида заданий:
  - Принести три разных вида еды. Повтор одного и того же продукта не засчитывается.
  - Принести часть брони. Аля особенно любит чёрные и белые цвета, розовый тоже подходит.
  - Поставить рядом с Алей декоративный блок, который она попросила.
- Задание можно попросить вручную: Shift + ПКМ пустой рукой по приручённой Але.
- Если рядом с владельцем нет активного задания, Аля может сама предложить новое примерно через 10 минут.
- Награды за задания: +1, +1,5 или +2 очка отношений.
- КД каждого типа задания — один игровой день. Активное задание, прогресс и КД сохраняются в NBT сущности.

## Управление
1. Призови Алю яйцом призыва или командой `/summon alisacompanion:alisa`.
2. Угости её печеньем или сладкими ягодами.
3. ПКМ по приручённой Але переключает ожидание и следование.
4. Shift + ПКМ пустой рукой показывает отношения и предлагает задание либо показывает прогресс текущего задания.
5. Для задания с едой передавай Але разные виды еды по одному.
6. Для задания с бронёй передай ей любую часть брони.
7. Для задания с декором поставь запрошенный блок не дальше шести блоков от Али.

## Сборка
Используй JDK 17 и Gradle 8.8. Из корня репозитория запусти:

```bash
gradle -p AlisaCompanion build --no-daemon
```

JAR появится в `AlisaCompanion/build/libs/`. В репозитории настроен GitHub Actions workflow для автоматической сборки.

## Примечание
Сборку и внутриигровое поведение нужно подтвердить через GitHub Actions и запуск Minecraft Forge 1.20.1. До такой проверки версия считается подготовленной к CI-проверке, а не протестированной в игре.
