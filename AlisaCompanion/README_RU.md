# Alisa Companion — Minecraft Forge 1.20.1

Проект мода-компаньона с персонажем Алей, основанным на предоставленном изображении.

## Требования
- Minecraft Java Edition 1.20.1
- Minecraft Forge 47.x (в проекте настроен Forge 47.4.28)
- Java 17 для сборки и запуска Gradle/Forge

## Возможности текущей версии 0.4.0
- Сущность-компаньон Аля и яйцо призыва.
- Приручение печеньем или сладкими ягодами.
- Следование за владельцем и переключение «сидеть / следовать» по ПКМ.
- Базовые анимации ходьбы, ожидания и сидения на основе PlayerModel.
- Дополнительная геометрия волос: чёлка, боковые пряди, задняя часть волос.
- Дополнительная геометрия худи: объёмный слой корпуса, нижняя кромка, рукава, манжеты и капюшон.
- Клиентская вторичная анимация на пружинной модели: волосы и нижняя кромка худи слегка отстают при ускорении и поворотах.
- Текстура 64×64 по референсу пользователя; русская и английская локализация.

## Что именно означает «физика» в 0.4.0
Сейчас реализована лёгкая процедурная spring-damper анимация на клиенте. Она учитывает скорость перемещения и изменение угла тела, затем плавно возвращает дополнительные части к нейтральному положению. Это не полноценная физическая симуляция: нет расчёта столкновений, ткани, ragdoll или независимых физических костей. Эти функции требуют отдельного расширения и тестирования.

## Ограничения модели
Текущая модель — переходный этап: основа по-прежнему использует стандартную геометрию PlayerModel, а авторские объёмные детали добавляются отдельным слоем. UV-развёртка рассчитана на текстуру персонажа 64×64. Внешний вид новых деталей необходимо проверить в реальном клиенте и при необходимости поправить UV/перекрытия.

## Управление в игре
1. Возьми яйцо призыва Али из творческого инвентаря или используй `/summon alisacompanion:alisa`.
2. Угости её печеньем или сладкими ягодами, чтобы приручить.
3. ПКМ по прирученной Але переключает режим ожидания и следования.

## Сборка на Windows
1. Установи JDK 17 (64-bit).
2. Распакуй проект в папку без кириллицы в пути, например `C:\MinecraftMods\AlisaCompanion`.
3. Открой папку в IntelliJ IDEA или VS Code с поддержкой Gradle.
4. Запусти `build.bat` (требуется установленный Gradle в PATH) или выполни `gradle build` при установленном Gradle 8.8.
5. JAR появится в `build\libs\alisacompanion-0.4.0.jar`.
6. Положи JAR в `.minecraft\mods` профиля Forge 1.20.1.

В проекте есть GitHub Actions workflow `.github/workflows/build.yml`: он устанавливает Java 17 и Gradle 8.8, собирает мод и сохраняет JAR как Artifact. Чтобы запустить вручную: открой репозиторий на GitHub → Actions → Build Forge mod → Run workflow. После завершения открой запуск и скачай Artifact `alisacompanion-forge-1.20.1`.

## Проверка
Исходники и структуру проекта проверили. В среде подготовки нет Gradle и доступа к серверу загрузки Gradle, поэтому компиляция Forge и запуск клиента здесь не подтверждены. Для получения JAR используй GitHub Actions по инструкции выше либо собери локально на Windows с JDK 17 и Gradle 8.8.
